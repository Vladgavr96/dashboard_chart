# 📊 Интерактивный дашборд: 4 Time-Series графика на Python + Plotly

Этот проект представляет собой автономное Python-приложение для визуализации четырех последовательностей данных (time-series) на одном интерактивном графике. 

Скрипт воссоздает стиль современного минималистичного дашборда, используя разные типы визуализации для каждой метрики:
1. **Area** (Область с заливкой) — например, для расходов (Cost).
2. **Bar** (Столбцы) — например, для CPA.
3. **Spline** (Сглаженная кривая) — например, для ROI.
4. **Line** (Линия с маркерами) — например, для конверсий (Conversions).

График имеет кастомный тултип (всплывающую подсказку), который объединяет данные всех метрик в одну карточку при наведении, а также поддерживает 4 независимые невидимые оси Y для корректного масштабирования разных по величине значений.

⚙️ Настройка приложения под свои данные
1. Замена данных
Найдите в коде блок # 1. ГЕНЕРАЦИЯ ДАННЫХ. Замените тестовые массивы на свои реальные данные.

Требования:

Все 5 массивов (dates и 4 массива значений) должны быть одинаковой длины.

Даты должны быть в формате, который понимает pandas (например, '2026-06-12').

# Пример ваших данных
    dates = pd.to_datetime(['2024-01-01', '2024-01-02', '2024-01-03'])
    data_cost = [150.5, 200.0, 180.2]       # Ваши расходы
    data_cpa = [2.5, 3.0, 2.8]              # Ваш CPA
    data_roi = [120.0, 140.0, 110.0]        # Ваш ROI
    data_conv = [15, 20, 18]                # Ваши конверсии

⚠️ Критическая настройка: Масштабирование осей (Range)
Поскольку у вас 4 метрики с разными масштабами (например, CPA = 1.23, а ROI = 161.47), график использует 4 невидимые оси Y (yaxis, yaxis2, yaxis3, yaxis4).

Если не настроить их диапазоны (range), линии будут выглядеть сплюснутыми или обрезанными. Найдите блок # 3. НАСТРОЙКА СТИЛЯ И ОСЕЙ и настройте range для каждой оси, исходя из максимальных значений ваших данных (добавьте 10-20% запаса сверху):

    yaxis=dict(..., range=[0, 600]),    # Для Cost (макс 500 + запас)
    yaxis2=dict(..., range=[0, 6]),     # Для CPA (макс 5 + запас)
    yaxis3=dict(..., range=[0, 350]),   # Для ROI (макс 300 + запас)
    yaxis4=dict(..., range=[0, 60]),    # Для Conversions (макс 50 + запас)
